Privacy policy

Last updated 8 October 2026

Nerfed is a Chrome extension that hides parts of YouTube and changes its layout according to your settings. It does not collect, sell or share any personal or usage data.

What it does on YouTube

Nerfed runs only on www.youtube.com. It hides page elements and adjusts the layout in your browser. It doesn't collect, store or send the content of the pages you visit.

Your settings

Which options you have switched on is saved with Chrome's storage (chrome.storage.sync). If Chrome sync is on, Chrome keeps these settings in step across your signed-in browsers. The developer has no access to them.

No network activity

Nerfed makes no network requests of its own and contains no analytics, tracking or advertising code.

This website

This site is hosted on GitHub Pages and loads no third-party scripts, fonts or trackers. GitHub may keep server logs, such as IP addresses, as described in GitHub's privacy statement.
